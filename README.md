# EcoCampus Challenge 🌿

A responsive student project that encourages eco-friendly habits on campus through challenges, points, progress tracking, and a sample leaderboard.

## Features
- Responsive dashboard with eco-points, completed challenge count, streak-style counter, and levels
- Nine challenges across waste, energy, water, and nature
- Earn points by completing challenges; filter by category
- Personal display name and sample leaderboard
- Eco activity counters and progress bar
- Rotating green tips
- Light/dark mode
- LocalStorage saves progress in the current browser
- Reset demo data button

## Technology
HTML, CSS, and vanilla JavaScript. No build step required.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `ecocampus-challenge`.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment. Expected URL: `https://YOUR-USERNAME.github.io/ecocampus-challenge/`.

## Notes
This is a front-end demo. Progress is stored only in the current browser and does not sync across devices. The leaderboard has sample entries and is not a live multi-user leaderboard. Environmental savings are not measured by this demo.
